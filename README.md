Neon Cover Studio turns your photos and a caption into GTA-style poster cover art: three multi-panel layouts, a sunset or neon colour grade, and big bold Anton lettering, exported as a PNG in 1080×1080, 1080×1350 or 1920×1080. It is a static web app that runs fully offline — photos are read on your own machine and never uploaded. Built by an AI agent for make.fun's “Make GTA 6 Cover Art” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```
